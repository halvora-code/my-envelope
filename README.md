My Snow Globe Project!

What it is: An envelope that shakes when you press it and gives you a message picked at random. 

How I made it:
This page was made using the help of the tutorial from the snow globe beginner guide using HTML, CSS, and JS. 

Some of the challenges I faced: 
At first when I started working on this project my Hackatime was not tracking my coding hours so I needed to troubleshoot that so 
that my time could be tracked. It was difficult since I use a linux distribution but after some time I finally figured it out.
After that the next challenge I faced was with github. It has been a while since I have made a public website but I eventually found
my way to creating a public link. 

What I learned:
I don't usually code in javaScript but I learned a few new variables and how they work which will be very helpful for future projects.
In CSS I learned how to use @Keyframes and transform,translateX. Doing this project was beneficial even though I learned a few small things
those small things are things I can use in the future. This project also motivated me to learn more JavaScript so I can do more cool features
for future projects.
